# Cosmorex v3.2 — стартовый экран и параллельные циклы

В этой версии главный опрос остаётся единственным основным запросом миссии.
Параллельные циклы работают как исследования на время ожидания следующего главного запроса.
Их ответы хранятся отдельно и не смешиваются с результатом главного опроса.

Добавлено:

- новый стартовый экран Первого экипажа;
- стартовое изображение `assets/cosmorex_start.jpg`;
- кнопка `Командный модуль`;
- отдельные кнопки главного опроса и параллельных циклов;
- хроника миссии;
- поддержка скачиваемого фона, если в проекте есть `assets/cosmorex_wallpaper.jpg`;
- сохранена база `cosmorex_survey.db`;
- автоматическая миграция старых циклов в главный тип;
- защита от запуска двух копий бота.

## Установка

1. Сохраните резервную копию `cosmorex_survey.db`.
2. Распакуйте архив поверх текущего проекта.
3. Базу `cosmorex_survey.db` не удаляйте и не заменяйте.
4. Запустите `bash restart.sh`.
5. В Telegram отправьте `/start`.

## Административные команды

Создать главный опрос:

`/admin_new_main 002 | Название | Вопрос 1 | Вопрос 2`

Создать параллельный цикл:

`/admin_new_parallel P002 | Название | Вопрос 1 | Вопрос 2`

Закрыть главный опрос:

`/admin_close итоговый текст`

Закрыть параллельный цикл:

`/admin_close_parallel P002 | итоговый текст`

Экспорт главного опроса:

`/admin_export`

Экспорт параллельного цикла:

`/admin_export P002`
